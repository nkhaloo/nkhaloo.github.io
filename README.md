# Academic Website

A blank static academic website inspired by the structure of https://pennydy.github.io/.

- `index.html`: Home
- `projects/index.html`: Projects
- `assets/Noah_Khaloo_Resume.pdf`: Resume (linked directly from navigation)
- `cv/index.html`: legacy page linking to the resume
- `assets/style.css`: shared layout and styling

Open `index.html` directly in a browser. No installation or build is required.
The profile column, page content, and footer are intentionally empty.
The Resume navigation link opens the included PDF directly.

These files can be hosted on GitHub Pages from a repository's root directory,
or on any static website host. Relative links also support repository subpaths.
