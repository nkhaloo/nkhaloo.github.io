Variable Acoustic Organizer (VAO)

https://github.com/nkhaloo/Variable-Acoustic-Organizer

Variable Acoustic Organizer, or VAO, is an end-to-end model that breaks up raw audio into different sound types—sonorants, obstruents, and silence—using acoustic information. This is useful for classification tasks using acoustic features, as certain acoustic features are only useful for certain sound types. This is a work in progress, though initial results are promising!
